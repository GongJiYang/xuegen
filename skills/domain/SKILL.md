# 领域

忘了的词来这里问（用户 2026-11-11 定）。v0 不接检索：一个科目的知识页整份放得进上下文（最大科目约 10 万字）。

## 入口

先按 `../wiki-save/SKILL.md` 的「入口与配置」用 `wiki.json` 定位库根；下文的「<库根>」都指它。**不要猜路径**，工作区里的目录（如 `sim/`）不是库。

## 范围

- 只查：这个科目的知识页 `wiki/knowledge/concepts/<科目>/`、科目页 `wiki/subjects/<科目>.md`（含「## 领域小结」）、这个科目下各门课的课程页 `## Learning Record` 与 `wiki/courses/<slug>/records/`。
- 不查：会话记录、闪卡、`raw/` 原书、别的科目。用户问的是别的科目的词，说出它在哪个科目，请用户去那个领域问。
- 词表与小结用本技能目录的脚本取（只读）：`node domain.mjs subjects "<库根>" --json`（各科目的概念页数、词数、有没有小结）、`node domain.mjs glossary "<库根>" <科目> --json`（按课次分组的词表 + 小结原文）。

## 回答

1. 先找：在词表里找这个词（中文、英文都比对）；找到就读它所在的概念页，必要时再读出处那节课的学习记录。
2. 答：三五句说清，先说它是什么，再说它和学过的哪个词有关。每个说法后面用 `[[页面路径|页面标题]]` 标出处；来自学习记录的写「你在 MM-DD 的课上见过它（CTM D2）」。
3. 库里没有：直说「<科目>的知识页和学习记录里都没有 X」，再说下一步——按路线哪一周期、哪门课会学到（看科目页与路线页，只读），或者在自由提问里问（那边的回答不进库）。**不用自己的知识补答。**
4. 学过但还没验收的（课程页里那一节是用户自报勾掉的），回答末尾提一句「这一节是你自报学过的，还没验收过」。

## 不做

- 不写文件、不调 `course_plan` / `course_close` / `cycle_open`、不制卡；用户要改什么，请用户回总控或那门课的会话。
- 不出检查理解题、不展开讲新内容；用户想深入学，建议开那门课的会话。
