# 字符图示例

每种图的 1-2 个中文示例，均通过 `diagram-check.mjs`（中文按 2 列计，框线对齐）。结构模式改写自 codex-preview 与 tldr-skill，标签与内容为 Xuegen 独立编写。

## 流程 / 方框图

```text
[输入原图] ─▶ [切分节点] ─▶ [布局连边] ─▶ [渲染字符]
                  │
                  └─▶ ◆ [检测交叉] ─▶ 超 6 节点改用 mermaid
```

方框内文字用名词短语；分支用 `┌ ┬ ┐` / `└ ┴ ┘`。竖线要与上下行连通。

## 二选一对比

```text
声明式模型                           命令式模型
────────────────────────             ────────────────────────
变量名 → 只读绑定                    变量名 → 可变单元
重新赋值：不合法                     重新赋值：合法
◆ 状态随时间只能前进                 ◆ 状态可随意改写
```

同列对齐即同一维度；把重点行用 `◆` 标出。

## 条形图（方块）

```text
各阶段耗时（毫秒）
解析      ████████████████░░░░  120
求值      ██████████░░░░░░░░░░   75
```

条形固定总宽（此例 20 格），未完成部分用 `░`；末尾标单位与数值。

## 状态板 / 矩阵

```text
专题进度                 已掌握  在学  未开
线性代数                   ◆      ○     ○
概率论                     ○      ●     ○
编程范式                   ●      ○     ○
```

`◆` 已掌握、`●` 在学、`○` 未开；表头写明每列含义。

## 树 / 分类

```text
变量
├─ 声明式
│  ├─ 只读绑定
│  └─ 每次构造新值
└─ 命令式
   ├─ 可变单元
   └─ 就地修改
```

同层缩进一致；层级用 `├─` `└─`。
