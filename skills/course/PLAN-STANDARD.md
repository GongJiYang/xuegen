# 标准计划输出

每门课一份 `wiki/courses/<course-slug>.md`，段落顺序固定为下面七段。`render-board.mjs` 按同一顺序渲染 `wiki/courses.html`，所以 Markdown 怎么写，网页就怎么显示；不需要为网页另写一份内容。

```
1 定位      标题 / 当前周 / 当前位置 / 状态源
2 下次起点  一句可执行的动作
3 本周      带完成条件的任务（唯一打勾处之一）
4 今日      当天能做完的 1–3 条（唯一打勾处之二）
5 总目标    3–5 条可判定的里程碑（唯一打勾处之三）
6 完整计划  周次 → 主题 → 交付/验收，纯参考，不带复选框
7 学习记录  日期 + 证据 + 结论 + 计划缺口
```

## 各段写什么

**1 定位** — H1 用课程名，不写口号。`## Key Facts` 里必须有 `- 当前周：`（格式 `W1 · 主题`，看板按它显示周次）。当前位置、阅读位置、材料来源都写实际状态；不知道就写「未确认」，不编造页数、版本或日期。

**2 下次起点** — 一条能立刻执行的动作，从最近一次记录里推出，不是重新规划。它回答「下次坐下先做什么」，不重复本周清单。

**3 本周** — 3–5 条，每天能推进其中一条。每条写成「动作 + 完成条件」，完成条件必须可观察（能画出什么图、能复述什么、跑通什么命令）。读几页不算完成，读懂并复述才算。

**4 今日** — 1–3 条，当天可完成，通常就是本周里的一条拆细。日期写实际日期和状态（例如「尚未开始」）；没有活动时如实写，不要为了凑数编任务。

**5 总目标** — 3–5 条可判定的里程碑，从低到高分档（最低 / 良好 / 出色），每条能被外人核对。「理解 X」不是里程碑，「能画出 X 并说明代价」才是。

**6 完整计划** — 表格或分组列表，给周次、主题、材料、交付物。此段只做参考：不带复选框，不统计进度，避免和上面三处勾选重复计数。

**7 学习记录** — 每次收课追加 `### YYYY-MM-DD-NN`，写：做了什么、证据是什么（用户原话或当场核实结果）、结论（勾了/没勾、为什么）、计划缺口。归档或迁移也要单独记一条并标明「非收课」。

## 硬规则

- 复选框只出现在 `## Overall Goals`、`## This Week`、`## Today` 三处；`## 计划表` 里出现复选框会被 `verify` 判为不一致。
- 勾选必须有证据。用户自报而未当场核对的，任务后标 `（用户自报，未检查）`；勾错按「抵消」处理：回到 `[ ]`、写撤销原因、留下原勾选时间，不物理删除记录。
- 数字是「已核实的计划项」，不是掌握率；不发明百分比。看板与截图都按同样口径。
- 计划缺口要显式写出来（例如某章未安排、某链接未核对），不假装覆盖完整。
- 修改顺序固定：`verify → unlock → 编辑 → 截图 → lock → dashboard → render-board`。

```markdown

## Overall Goals

- [ ] 阅读路线完成：29 篇全部读毕，每篇三行笔记（主张 / 证据 / 最可能错）

- [ ] 良好：明确回答 Pythia 多义性主要来自 H1/H2/H3，并给出跨层、跨规模规律
- [ ] 出色：发现 H1/H2/H3 均未预测到的模式

## This Week

- [ ] 基础自查：确认线性代数（矩阵乘法 / 特征分解 / 子空间与投影）、PyTorch、Transformer 结构是否熟练
- [ ] 搭建 ARENA 第 1 章环境（TransformerLens），跑通第一个练习
- [ ] 读 Zoom In: An Introduction to Circuits，写三行笔记（主张 / 证据 / 最可能错）

## Today

日期：2026-10-17（课程创建，尚未开始学习）

- [ ] 概念页无活动；从下方 Next Session 的第一步开始

## Next Session

从计划确定的第一步：先做基础自查（线代 / PyTorch / Transformer 结构），然后搭建 ARENA 第 1 章环境并跑通第一个练习。

## 计划表（参考；勾选只出现在上方 Overall Goals / This Week / Today）

### 2026-10-17-01（课程创建，非收课）

- 创建课程页并建立阅读路线（29 篇，链接逐篇核对）与课题里程碑计划表。
- 尚未开始学习；无作答或阅读证据。
```

对应网页看板：`wiki/courses.html#course-mech-interp` — 顶部是「下次起点」，接着本周 x/y、今日 x/y、总目标 x/y，再是完整计划表与可折叠的学习记录；页面没有输入框或按钮。
