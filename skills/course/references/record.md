# 收课记录样例（Learning Record）

照这个样子写，**不要去读脚本源码推断格式**。脚本只认两处：标题 `### YYYY-MM-DD-NN`，和紧跟其后的 `完成：` 行。

```markdown
### 2026-11-07-01（收课：D1 · Ch1 §1.1–1.4）

完成：D1

- 课次：D1，内容 …（一句话）。
- 已通过的检验（有当场作答）：…（每条写题目、用户原答要点、结果）
- 未满足条件：…（哪个任务、为什么保持 `[ ]`）
- 未验证：…
- 存库：概念页 [[…]]、[[…]]；卡片见第 10 步（确认后才写）。
- 下一次：…
```

- `完成：` 后写计划表「天」列的 id，多个用顿号：`完成：D3、R1-D2`；这一节没完成就**不写这一行**。
- 标题序号按当天第几条记录递增，已有标题不复用。
- 写完后运行一次 `node course-state.mjs list "<库根>/wiki/courses" --json`（本技能目录），看这门课的 `week.done`（本周已完成数）是否加上了；没加上，多半是 `完成：` 行的 id 与计划表不一致，对照计划表改这一行即可。
