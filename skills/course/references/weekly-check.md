# 周核实（整合日）

用户在整合日点「核实 →」或说「做本周周核实」时：

1. **确认主项课**：只对**主项课**做；辅助课不核实。确认已选定那门课，重新读课程页。
2. **出无提示题**：找 `This Week` 里的「周核实」项和本周已完成课次。按它们的完成条件，出 2–3 道**无提示**的题（用 `teach` 的「检查理解」框），覆盖本周最核心的关系；不要用讲解代替出题。
3. **核对并记录**：用户作答后按 `SKILL.md`「收课」第 2 步核对：满足条件才把周核实项打 `[x]`，写一条 Learning Record（`周核实 Wn：x/3 独立完成`，附题目与结论）。打勾和记录照收课一样经 `course_close` 一次事务写（`stage` → 改暂存课程页 → `check` → `commit`），不直接写课程页。答不出的标「仍有错误」，列入下周第一节的回忆题。
4. **汇总给总控**：结束时一句话汇总给总控（「CTM W1 周核实 2/3」），由总控写进周期页 Log。
