## 要修的问题

1. **总进度面板排版坏了**：真实课程名很长（如「CTM 7 周学习计划」「DeepInfer 推理框架拆解（DeepInfer + …）」），被挤进窄列，与周标签、上次日期、百分比互相重叠。改为：第一行课程名（单行，超长省略号，悬停显示全名）；第二行进度条 + 百分比；展开后周标签、「本周 x/y」、「上次 日期」各自成行，不与进度条同一网格。用 6 门真实课程名截图确认无重叠。
2. **阅读优先级没传下去**：选「高」后加入，生成文件里是 `priority: medium`。修正并加测试（选中值 → `reading.add` 的 `priority`）。
3. **阅读面板只显示今天到期的**：新加入的文章到期是明天，面板却显示「队列是空的」，用户看不到刚加的东西。改为显示整个队列（排除 `done`），按到期日排序，每项右侧标签「今天 / 逾期 N 天 / 11月5日」；标题「今天该读（N）· 队列共 M 篇」；加入成功后给提示「已加入：<标题>，<到期日>」。
4. **关闭技能后 `/` 菜单里仍然有它**：关闭 `article` 后 `desktop.json` 的 `disabledSkills` 已写入、勾选已取消，但 `/skill:article` 仍在 `/` 菜单。菜单过滤必须立即生效（用本地 `disabledSkills` 过滤 agent 命令表，不等重取）。加测试。
5. **技能说明太长**：直接显示整段 description，一个技能占十几行。默认只显示第一句（到第一个「；」或「。」，最多 2 行），点技能名展开全文。
6. **日历**：周一开头（设计稿是「一 二 三 四 五 六 日」）；✎ 在格子里出现了两次（右上角 + 标记行），只保留右上角；保存后详情区应切到刚保存的那一天。
7. **卡片输入**：「正面」输入框按设计稿占满整行。
8. **模型错误直接显示原始 JSON**（如 `401 {"type":"error",…"invalid x-api-key"…}`）。在 core 把常见错误转成中文：认证失败 →「模型认证失败：请在终端运行 xuegen login 重新登录」；429/限流 →「请求太频繁，稍等再试」；网络 →「连不上模型服务，检查网络」；其余 →「模型出错了」。原始信息放在可展开的「详情」里。警告框与消息内都用转换后的文案。加测试。
9. **风格存错地方**：没有进行中的课程时输入 `/细讲`，结果写进了「接着上次」那门课的 `courseStyles`。规则：只有通过「继续学习 / 开始学习」开始了某门课的会话，风格才记到该课程；否则记到 `sessionStyle`。加测试。
