## 二、尺度（一套变量，全部散值换成它）

**字号**（取 Radix 1–6 级，字号与行高成对使用，不混用）：

| 变量 | 字号 / 行高 | 用途 |
|---|---|---|
| `--fs-1` | 12 / 16 | 说明、标签、日历格内文字（最小，不再有 9–11.5px） |
| `--fs-2` | 14 / 20 | 界面默认：面板正文、按钮、列表行 |
| `--fs-3` | 16 / 24 | 面板小标题、今日卡标题行 |
| `--fs-4` | 18 / 26 | 面板主标题 |
| `--fs-6` | 24 / 30 | 大数字（预计结束日期、卡片总数） |
| `--bear-body-size` | 用户设定 | 只给对话正文用；今日卡、提示条、工具行不跟它放大 |

**字重**：400 正文、500 强调（按钮、当前行）、600 标题。去掉 650 / 700。

**灰阶**（照 Radix 12 级的分工，暖灰，基于现有 paper/ink 补齐）：

| 级 | 用途 | 值（初稿，截图里再调） |
|---|---|---|
| 1 | 窗口背景 | `#fbfbfa`（现 paper） |
| 2 | 次级背景（侧栏、代码块） | `#f5f5f4` |
| 3 | 控件默认底 | `#efefee` |
| 4 | 悬停 | `#e8e8e7` |
| 5 | 按下 / 选中 | `#e1e1e0` |
| 6 | 分隔线（不可点） | `#e6e6e4`（取代 hairline 与 `#eceef0`） |
| 7 | 可点元素的边框 | `#d9d9d6`（取代 rule） |
| 8 | 强边框、焦点环 | `#bcbcb8` |
| 11 | 次要文字：在 1–5 级任一背景上都 ≥ 4.5:1 | `#63635f`（取代 soft 作文字；1 级上 5.8:1，5 级上 4.6:1） |
| 12 | 正文 | `#1f2124`（现 ink） |

- `--faint` 不再用于文字，只用于装饰记号（◌）和禁用态底色。
- 强调色拆两级：`--accent-9 #1aa3ff`（圆点、进度条、选中下划线）；`--accent-11 #0a65a0`（链接文字与焦点环，1–5 级背景上都 ≥ 4.5:1）。琥珀、绿同理补一个文字级，红保留。

**间距**（4px 基数）：`--sp-1 4px`、`--sp-2 8px`、`--sp-3 12px`、`--sp-4 16px`、`--sp-5 24px`、`--sp-6 32px`、`--sp-7 48px`。1/2/3/5/6/7/10/14/15/18/20/28 全部就近归入。

**圆角**：`--r-1 4px`（按钮、输入框、标签）、`--r-2 8px`（卡片、弹出层），`999px` 只给胶囊，`50%` 只给圆点。

**边框**：只有 1px。分隔线用 6 级，可点元素用 7 级；2px 只留给焦点环和选中标签的下划线。

## 三、主次与分组（逐屏）

总原则：每屏只有一个最突出的东西；次要信息用颜色和字号弱化，不加粗、不加框；分组靠间距（组内 8、组间 24），不再每块都套卡片。

| 屏 | 现在 | 改成 |
|---|---|---|
| 总控首屏 | 今日卡跟正文放大，四行都同样醒目；卡下紧接旧对话 | 今日卡用界面字号（标题 fs-3、行 fs-2）；当前要做的那一行（●）字重 500 + 正文色，其余行次要文字色；「让总控说说」accent-11 文字链接；卡片只保留 6 级细边、去掉阴影 |
| 课程会话 | 输入框上方「总结 · 制卡 · 收课」与风格四档同级 | 风格四档弱化为次要文字，当前档下划线；三个动作按钮正文色 |
| 右侧面板（今天 / 总进度 / 阅读 / 卡片 / 日历 / 技能） | 标签行、各区标题、列表行字号各异，区块间用线分 | 面板标题 fs-4/600；区块标题 fs-1 次要文字大写间距；区块之间 24px 空白代替横线；列表行 fs-2，行内说明 fs-1 |

**设计稿自查（11-08，对照五条规则后改）**：
- 今日卡标题行（「C1 · 第 2 周 · 周一 · 深度日」）是说明，不是任务：降为 fs-1 次要色；当前那一行升为 fs-3、500、正文色，它的按钮带 3 级底色——每屏只有它最突出。
- 次要文字在悬停 / 选中底色上会掉到 4.1:1，灰 11 级与 accent-11 都加深一级（见上表）。
- 每个用字号变量的地方同时用对应行高变量，不混用。
- 内边距不再出现 2px，最小 4px。
- 输入框静止时 7 级边框（只有 1.4:1，靠底色和占位文字辨认）；悬停 8 级，聚焦 accent-11。
- 设计稿补了「回答中 / 加载中」（按钮禁用、面板「正在读取…」）与「长中文」开关。

## 四、状态补齐

- **焦点**：一条全局规则 `[data-skin="bear"] :is(button, a, input, textarea, [role="tab"], [role="menuitem"]):focus-visible { outline: 2px solid var(--accent-11); outline-offset: 2px; }`（焦点环要对背景 ≥ 3:1，8 级灰只有 1.8:1，所以用 accent-11），各处删掉 `outline: none`。
- **悬停**：所有可点的东西悬停时底色 4 级或文字变正文色，二选一，按元素类型统一。
- **选中**：标签页、风格档位用 2px 下划线（accent-11——非文字指示要 ≥ 3:1，accent-9 只有 2.6:1，只用于圆点等装饰）；列表行用 5 级底色。
- **禁用**：文字用 8 级灰 + `cursor: not-allowed`，不再用整体透明度。禁用文字不受 4.5:1 限制（WCAG 1.4.3 豁免），8 级灰正是为了让它一眼看出「点不了」；可点的次要文字一律 11 级。
- **加载**：面板加载中统一显示一行次要文字「正在读取…」，不留白屏。
- **次要文字下限**：任何文字对背景 ≥ 4.5:1（11 级灰满足）；装饰记号不受限。
