## 四、做一套新皮肤的顺序

1. 读 `UI-ARCHITECTURE.md` 与本台账第一节；在 `skins/README.md` 登记（状态「开发中」）。
2. 先让契约测试通过：实现 `SkinSlots` 全部插槽（可先照 bare 的语义 HTML 起步）。
3. 按第二节逐行实现，每行的「行为要点」都要做到；做到一行就在台账里给新皮肤加一列打 ✓ / ◐。
4. 画廊（`?gallery&skin=<id>`）每个插槽有设计；写 `docs/desktop/skins/<id>.md`。
5. 真实窗口按「任务清单」走一遍（开课、上课答题、收课、周五核实、周六读书、看总进度、改计划、复习卡片、改讲解偏好、回到某天的会话）。
