# Chicago 1.9

经典 Mac OS（System 6，1984–1991）的黑白像素界面，参考 [system.css](https://sakofchit.github.io/system.css/)（MIT），但不引入它的样式（它按 18px 设计，与 12px 像素网格不合），只取其中的 ChicagoFLF 字体。名字取自当年的系统字体 Chicago。

**视觉基准**：用户已确认的设计稿 `/Users/gjy/pi-learning/design/chicago/index.html`（仓库外，不入库；`?demo=big,focus`、`?demo=error`、`?demo=think` 可直接看各状态）。像素细节（尺寸、间距、边框、抖动图案、按钮圆角、动效步数）以设计稿为准，实现时直接移植其 CSS 与交互逻辑，不自行发挥。

**气质**：一台安静的老 Mac，屏幕上只有你正在读的东西。1 位黑白、像素字、细线窗口。极简，专注阅读；所有「设计感」来自真实的 System 6 细节，不加任何现代装饰。

## 1. 硬性约束（1 位显示器原则）

- 只有两种颜色：黑 `#000000`、白 `#FFFFFF`。中间色只能用**抖动图案**（棋盘格、50% 网点）表达，不用灰色、不用透明度、不用阴影（下拉菜单的 1px 实心黑色偏移除外）、不用 CSS 圆角。按钮与默认按钮外圈的圆角用逐像素绘制的 SVG `border-image`（见设计稿 `.btn`、`.def`），不得用 `border-radius`。
- 所有动画用**阶梯缓动**（`steps(n)`）或瞬时切换，不做平滑淡入淡出——1 位屏幕没有半透明。
- 像素字只用整数倍字号渲染，并关闭字体平滑（`-webkit-font-smoothing: none; font-smooth: never`），保持像素锐利。
- **例外（1.8）**：只有消息正文可以切换成系统平滑字体（黑体 / 楷体 / 宋体），见第 6 节。菜单、窗口标题、按钮、面板、代码与字符图仍全部使用像素字并关闭平滑。平滑正文字体会产生抗锯齿中间像素，因此「1 倍截图只有两色」的验收只在像素字体（默认）下成立；选用平滑字体时，颜色约束仍只针对配色，不针对字体抗锯齿。
- 不出现 emoji、彩色图标、渐变。图标为 1 位像素图（16×16 或 32×32）。

## 5. 微交互（细节要丝滑，但要像 System 6）

全部用阶梯缓动或瞬时切换；时长 ≤ 250ms；减少动效时按右列处理。

| 意图 | 动效 | 实现要点 | 减少动效时 |
|---|---|---|---|
| appear（窗口、对话框出现） | **缩放矩形**：从触发点到目标窗口画 6 个逐步放大的虚线矩形，每帧 1 个，总 180ms，然后窗口瞬间出现 | GSAP 时间线 + `steps`；矩形为 1px 虚线框，画完即移除 | 窗口直接出现 |
| appear（新消息） | 消息块按行「打印」出现：每 16ms 揭开一行像素高度（逐行遮罩），总时长不超过 200ms | 遮罩高度阶梯动画 | 直接出现 |
| confirm（选择菜单项） | 选中项**闪烁 3 次**（反白 / 还原，每次 40ms）后菜单收起 | 系统原版行为 | 闪烁 1 次 |
| confirm（按钮按下） | 按下即反白，松开还原；默认按钮回车触发时同样反白 80ms | `:active` + 程序触发的 class | 同左 |
| busy（思考中、工具运行） | 条纹进度条的斜纹每 120ms 平移 2px（阶梯）；工具行前的图标在两帧间切换 | CSS `steps` 动画 | 静态条纹 |
| expand / collapse（工具明细） | 披露三角 ▸ → 斜 45° → ▾ 两步旋转，各 40ms；明细区瞬间展开 | 阶梯旋转 | 直接切换 |
| progress（进度、计数） | 进度条以 4px 为一格逐格增长；数字逐位翻动（每位 30ms） | `steps(n)`，n = 格数 | 直接到终值 |
| alert（出错） | **菜单栏反白闪一下**（System 6 的视觉提示音），随后警告框以缩放矩形出现 | 菜单栏反白 100ms | 只显示警告框 |
| 流式输出 | 正文末尾一个实心块光标，530ms 闪烁（瞬时切换） | CSS `steps(1)` | 不闪烁的块 |

不做：入场编排、滚动驱动动画、视差、平滑淡入淡出、弹性缓动。

## 6. 字号与可读性（1.8）

- 消息正文可以随时切换字体（「显示 ▸ 正文字体」）：像素 / 黑体 / 楷体 / 宋体。字体效果因人而异，由用户试读决定；换字体不改配色、不改界面与代码/字符图的像素字。
- 字体族：黑体 `"PingFang SC", "Hiragino Sans GB", "Heiti SC", sans-serif`；楷体 `"Kaiti SC", "STKaiti", "KaiTi", serif`；宋体 `"Songti SC", "STSong", "SimSun", serif`。只用系统字体，不打包字体文件。
- 字号档位随字体：像素只允许 12 / 24px（整数倍保持锐利）；平滑字体允许 15 / 18 / 21 / 24px。切换字体时当前字号吸附到新字体的最近档位；⌘0 回到该字体默认档（像素 24px，平滑 18px）。
- 非像素字体对正文打开抗锯齿（`-webkit-font-smoothing: antialiased`）；代码、字符图、界面元素仍关闭平滑。
- 阅读版式：段落与列表最大行宽 `36em`（约 36 个中文字），行高 1.6（像素字体维持 20 / 40px 网格），段间距 0.75 倍字号；表格、代码、字符图不受 36em 限制。
- 生成时滚动：新回答开始流式输出，视口把该回答的开头对到顶部后就不再自动下滚；用户手动滚动，「回到最新」按钮保留。
- 专注模式下对话窗口居中、最大宽 720px，侧窗收起，菜单栏保留。

## 9. 防闪屏

- 字体 `font-display: block` 并预加载；字体就绪（最长 800ms）前页面只显示 `--paper` 底色。
- Electron 窗口 `backgroundColor` 取当前配色的 paper，窗口在 `ready-to-show` 后再显示；切换配色时同步更新窗口底色，避免深色配色启动时先闪白。
- 菜单栏「警示闪烁」用 ink/paper 互换实现，不用 `filter: invert`。

## 10. 终端字符图（box drawing、方块、盲文、箭头）

学根的回答会包含终端风格字符图（见 `docs/skills/` 中的画图 skill）。Fusion Pixel 等宽字体把 `─│┌█▓→■` 等画成全角（12px），与 6px 的英文错位，因此：

- 代码字体栈：`Fusion12Diagram, Fusion12Mono`；中文按 2 列（12px）对齐，符合 `east_asian_width` 的 W/F 规则。
- `diagram` 节点：无边框、无内边距，行高 = 字号 × 4/3（12→16，放大后 24→32），超宽横向滚动，禁止缩放。
