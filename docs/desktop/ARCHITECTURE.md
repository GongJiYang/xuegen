# Xuegen 桌面版骨架

本文件是桌面版的设计边界，服从根目录 `ARCHITECTURE.md` 的六层模型。桌面版只新增 L5（交互与验证）的一种界面，不新增运行时、不复制状态。

## 1. 目标与非目标

**目标**

- 可视化：表格、公式、图表在应用内原生渲染，不再依赖终端或切换浏览器。
- 常驻课程看板：随时看到整体进度，状态变化实时刷新。
- 边学边记：笔记面板直接编辑 Markdown。
- 模型与平台无关：沿用 Pi 的提供商与模型选择，不绑定任何一家。
- 后续可扩展：新增渲染类型、面板、技能时不改核心。

**非目标（当前不做）**

- 分发给他人：安装包签名、自动更新、多用户。
- 替换运行时：不 fork Pi，不引入第二个 agent 框架。
- 第二套状态存储：不引入数据库，Markdown 仍是唯一真相源。

## 2. 与六层模型的对应

| 层 | CLI 现状 | 桌面版 |
|---|---|---|
| L0 目标与事实 | `instructions.md` | 不变，共用 |
| L1 状态与记忆 | Pi 会话、`~/.xuegen`、Wiki Markdown | 不变，共用同一目录与文件 |
| L2 教学策略 | `skills/teach` 等 | 不变，共用 |
| L3 能力与工具 | skills、脚本、MCP | 不变，共用；渲染器注册表是 L5 的扩展点，不是新工具 |
| L4 运行时 | Pi CLI | Pi SDK，同版本，配置等价 |
| L5 交互与验证 | TUI | Electron 窗口：对话、看板、笔记 |

## 3. 进程划分

```text
┌──────────────── 渲染进程（React，沙箱） ────────────────┐
│  对话区 · 课程看板 · 笔记面板 · 渲染器注册表              │
└───────────────▲─────────────────────────────────────────┘
                │ preload：最小类型化 API（contextBridge）
┌───────────────┴──────── 主进程 ─────────────────────────┐
│  窗口 · 菜单 · IPC 路由 · agent 进程守护 · 文件监听        │
└───────▲─────────────────────────────────────▲───────────┘
        │ 消息协议（shared/）                   │ 只读监听
┌───────┴──────── agent 进程（utilityProcess） ┐   wiki/courses/*.md
│  Pi SDK 会话：模型、工具、skills、MCP、会话持久化 │   notes/*.md
└──────────────────────────────────────────────┘
```

原则：

- agent 进程崩溃不拖垮窗口；主进程负责报告并可重启。
- 渲染进程不直接访问文件系统和网络，只能通过 preload 暴露的 API。
- 消息类型只在 `shared/` 定义一次，三个进程共用。

## 4. 状态与写入边界

| 数据 | 真相源 | 谁能写 | 桌面版如何展示 |
|---|---|---|---|
| 登录、设置、会话 | `~/.xuegen/`（`XUEGEN_HOME`） | Pi 运行时 | 模型列表、会话列表 |
| 课程状态 | `wiki/courses/<slug>.md`（0444） | 仅 agent 经 `course-state.mjs` 解锁→编辑→上锁 | 看板只读；显示 `verify` 结果 |
| 课程看板 | `wiki/courses.md`、`wiki/courses.html` | 脚本生成 | 桌面版不读这两个派生物，直接解析状态源 |
| 自由笔记 | 工作目录 `notes/` 或用户指定的 Wiki 页 | 用户（笔记面板）与 agent | CodeMirror 编辑 + 实时预览 |

- 看板界面没有任何编辑入口，与 `course-board` 技能的只读约束一致。
- 课程文件解析逻辑与 `render-board.mjs` 共用同一模块，保证 CLI 网页看板与桌面看板一致。抽取方式在需要时（第 2 批）再定。
- 笔记面板与 agent 同时编辑同一文件时，以磁盘为准并提示冲突，不静默覆盖。

## 5. 与 CLI 共存

- CLI 入口 `bin/xuegen.mjs` 行为不变，可随时切回终端。
- 两者共享 `~/.xuegen`：同一份登录、同一批会话；桌面版启动时默认继续当前工作目录的最近会话。
- 会话配置等价：关闭自动发现，只加载仓库 `skills/`，追加 `instructions.md`，启用 MCP 与 tool-search。

## 6. 渲染器注册表（可视化扩展点）

模型只输出声明式内容，前端按代码块语言渲染；不执行模型生成的代码。

| 代码块语言 | 渲染 | 批次 |
|---|---|---|
| Markdown 正文、GFM 表格 | Streamdown | 1 |
| `math` / `$…$` / `$$…$$` | KaTeX | 1 |
| `mermaid` | Mermaid | 1 |
| `markmap` | Markmap（知识层级，配合 `article`） | 4 |
| `vega-lite` | Vega-Lite（数据图表） | 4 |
| `function-plot` | 函数图像（数学类学习） | 按需 |

新增类型 = 注册一项（语言名 → 组件），不改对话区代码。未注册的语言按普通代码块显示。

## 7. 技术选型

| 关注点 | 选型 | 理由 |
|---|---|---|
| 桌面壳 | Electron + electron-vite | Pi 是 Node，进程内直接用 SDK |
| 界面 | React 18 + TypeScript strict | 生态最全，AI 生成最稳 |
| 界面 | 可替换皮肤（见 `UI-ARCHITECTURE.md`），首套为 Chicago（system.css） | 界面会频繁更换；逻辑与外观分离 |
| 动效 | 意图 API + 皮肤预设；GSAP 仅限皮肤内部 | 只做细节微交互；尊重减少动效设置 |
| 布局 | react-resizable-panels（需要停靠时换 dockview） | 先简单 |
| 笔记 | CodeMirror 6 | 保持纯 Markdown，兼容 Obsidian |

## 8. 安全底线

- `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`。
- 凭据只存在 `~/.xuegen/auth.json`，不进入渲染进程、日志或仓库。
- 外部链接用系统浏览器打开，不在应用内导航。
