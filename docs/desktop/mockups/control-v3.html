改了什么（对照现在）

位置现在v3为什么
首屏顶部六个数字格，两行，约 210px一行状态，约 36px；点了跳到对应区块格子里的数字大多不用每次看；腾出地方给今天和周表格
今天外框里再套一个框；拖欠的排最前去掉一层框；今天排的在上，拖欠的收成一行打开总控先看到今天要做的，不是一串「原排」
上课行只有「开课 →」悬停多一个「⋯」：学过了 / 挪日子 / 这节讲什么强制结课的入口；挪日子以前只能打字说
自报勾掉的行—✓ +「自报」小标签，右侧「补验收 →」和真正验收过的分开，不混
动态卡第一行是你说的话（粗），结果在下第一行是结果，你说的话变小灰字回头看时关心的是改了什么
领域没有页面底部一行科目入口领域总控的入口（另见 domain.html）
不变周 / 月表格、书房、卡片区、横幅与改动标记、标签页、快捷键（⌘0 回总控）都照旧；窄窗口（≤ 900px）状态一行折成两行

1六格改成一行，可以吗？（书房「预计 02-02 读完」、卡片「共 501 张」这类副文字会只在点开后看到）
