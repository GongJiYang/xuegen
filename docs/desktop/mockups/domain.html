  5. 异常靠弹语义栈找到 catch，实现错误围隔。

闭包与静态作用域

closure · static scoping

过程值不只是代码：创建它时，抽象机把过程体里用到的自由标识符（free identifier）在当时环境里的绑定一起打包，叫上下文环境。代码 + 上下文环境 = 闭包。

所以调用发生在哪里不影响结果——标识符指向什么，在定义的那一刻就定了，这就是静态作用域。
