设计稿：`/Users/gjy/pi-learning/design/animate/src/dash.{jsx,css}`（`http://localhost:5181/?d=dash`，截图 `/tmp/dash-shots/`）；加书对话框沿用 `plan2.jsx` 的 `AddBook`（第 6 屏）。清单：`docs/desktop/FEATURE-UX-CHECKLIST.md`（A 级，全过）。

## 功能卡
| 字段 | 内容 |
|---|---|
| 用户任务 | 打开学根一眼看全：今天做什么、这周 / 这月排了什么、周期和书读到哪、Anki 与卡片情况；要改的跟总控说 |
| 入口 | 打开学根默认落在总控会话 = 面板；总控里**不显示**「课程与计划」按钮和侧栏；课程会话不变 |
| 默认状态 | 状态格 + 今天 + 本周（周 / 月切换，默认周）+ 总进度 / 书房 / 卡片；聊天栏宽窗开、≤ 900 收起 |
| 成功结果 | 点格子 → 左边「今天」换成那天（+「回到今天」）；行内按钮开课 / 带读 / 读完这段 / 打开 Anki；书房按钮发话给总控 |
| 数据来源 | 现有：`useControlPlanbook`（周 / 日 / 月）、`cycle.overview`、`shelf.list`、`cards.stats`、`anki.status`、`subjects`。**同一事实在别处的显示**：今天的课次与完成（课程会话侧栏「今天」、总进度）、Anki 张数（今日卡、侧栏卡片）——都走 `consistency.test.ts` 里已有的共用函数 |
| 改库 / 撤销 | 读完这段：10 秒撤销（第 1 档）；排书、改读法、设目标、暂停 / 恢复：发话给总控，聊天里给看改动、说可以才写（第 2 档）；面板本身不直接写库 |
| 含 AI | 是（按钮发话给总控） |
| 契约 | 新 `ControlPanel` 插槽替换 `Planbook`；bare / chicago 最小实现 |

## 宽屏 1920（用户 11-12 特别要求，验收重点）
设计稿已加「1920 宽」一档（默认），截图 `/tmp/dash-shots/1-面板.png`；1440 见 `7-1440.png`，900 见 `6-900宽.png`。规则：
- 面板内容最宽 **1480px**、在聊天栏左边的区域里居中；多出来的宽度留白，不把格子拉宽。
- 周表格格子只写短内容（「离散 D3」「带读 C 语言 Ch1」），最多两行、多的省略号；完整内容点开那天在「今天」块看。
- 「今天」块固定在左（约 2 / 7 宽），行内按钮紧跟在文字右边那一栏，不跑到屏幕最右。
- 聊天栏宽 340px 不变。
- 验收：1920、1440、900 三档真窗口截图与设计稿同宽并排；量 `.bear-dash` 内容宽度 ≤ 1480、周表格每列宽、格子文字行数 ≤ 2。

## 顺手认领的待办（ROUTE「待办总表」）
