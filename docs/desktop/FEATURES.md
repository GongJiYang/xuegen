# 桌面版「可用」功能总表（2026-11-03 用户需求）

用户的定义：每个功能都有**输入**和**输出**，输入位置一眼可见；在输入框打 `/` 能看到功能；每次会话可选讲解风格。视觉基准：`/Users/gjy/pi-learning/design/chicago/features.html`（仓库外，`?tool=progress|reading|cards|calendar|skills`、`?demo=slash`、`?demo=day` 看各状态），沿用已确认的 Chicago 皮肤（`chicago.md`）。

## 用户习惯（来自真实会话与库，决定设计）

- 只说过「大白话」，从没说过「深度」；而且每次新会话都要重复说——**风格要按课程记住**。还常说「按细的讲」「一次只讲一个模块」。
- 会话开头常是「继续 / 开始今日教学 / 之前学到哪了」，结尾是「今天学到这里，写进 wiki，更新计划」——需要「接着上次」入口与一键收尾。
- 读原文与跟学根学分两天做；一次读太多会累——阅读按位置分段推进。
- 约 470 张卡，仅 192 张已同步（有 `<!--ID-->`）；10 月 15 日后没有制卡。
- 库里没有日记约定；日期信息散在学习记录标题、计划表、阅读 `due`、`wiki/log.md`。

## 功能 × 输入 × 输出

| 功能 | 输入（用户在哪里操作） | 输出（看到什么） | 数据（唯一真相源） |
|---|---|---|---|
| 风格 | 输入框上方单选「大白话/细讲/深度」；「风格」菜单；`/大白话` 等；总进度里每门课的单选 | 用户消息前的风格标签；学根按风格讲 | `desktop.json` 的 `courseStyles`；消息前缀 `[风格：X]`；`teach` 的风格规则 |
| `/` 菜单 | 输入框第一个字符打 `/`，上下键选，回车执行 | 分组列表：风格、学习、阅读、卡片、日历、技能（已启用的 `skill:*`） | 内置命令表 + agent 返回的技能列表 |
| 今天 / 接着上次 | 「继续学习」按钮；「学习 ▸ 今天学到这里」⌘E | 今天计划（悬停/点击列出当天具体项）、到期阅读、待同步卡片数；上次课程、日期、下次起点 | 课程文件 `Next Session`、阅读 `stats`、卡片统计 |
| 总进度 | 点课程展开；每门课选风格；「开始学习」 | 每门课总目标进度条、当前周 x/y、本周任务勾选（只读）、上次日期、下次起点 | `course-state.mjs list --json` |
| 阅读 | 顶部「加入阅读」输入框 + 优先级；每项「下次接着读 / 推迟 / 读完」 | 今天该读列表：标题、优先级、位置、到期 | `reading-queue.mjs`（add/today/review/stats） |
| 卡片 | 「新卡片」正面/背面/牌组 +「存为新卡」；「让学根起草」 | 总数、待同步、各牌组同步比例；Anki 状态（未打开时明确提示） | 扫描 `wiki/flashcards/`；新卡写入库；AnkiConnect **只读** |
| 日历 | **双击某天**打开编辑框写入；单击看当天详情；◀ ▶ 翻月 | 月历格子上的标记：● 学习记录 ◆ 计划 ▲ 阅读到期 ✎ 笔记；当天详情 | 新 skill `calendar`：聚合上述来源；笔记写 `wiki/calendar/YYYY-MM-DD.md` |
| 技能 | 每个技能的启用勾选；「安装技能」输入仓库地址 →「获取」（进待审核区） | 技能名、`/skill:名`、说明、来源（内置/个人/待审核） | `lint-skills.mjs --json`；`desktop.json` 的 `disabledSkills`；`~/.xuegen/skills/` |
