## 1. course（207 行）— 课程状态与流程

依赖：teach、wiki-save（入口、制卡）、cycle-plan（`cycle.mjs`）、reading（`note`、书房）。课程会话里的一切写入只经 `course_close`；总控里建课、改计划走「解锁 → 编辑 → 截图 → 上锁 → 刷新看板」（:16–18）。

### 1.0 总控写入路径（11-10 整理 1 起：计划事务）
1. 写前校验 — `course-state.mjs verify`（bash，只读）— 不写
2. 开计划暂存 — `course_plan stage`（新建课程加 `new` + `subject`）— 建暂存
3. 改暂存副本 — 编辑工具改课程页 / 科目页 / index / log — 写暂存
4. 排期（需要时）— `course_plan schedule`（暂存里跑 `course-schedule.mjs plan --write`）— 写暂存
5. 校验 — `course_plan check` — 不写
6. 提交 — `course_plan commit`：原子落盘、上锁、重画看板、jj「计划」— 写库

### 1.1 定位课程（:39，1–4）
1. 读库配置 — `wiki.json` — 不写
2. 选课程 — 指定的 / 已选的 / 搜索，多个让用户选 — 不写
3. 新建课程文件 — 用户要求才建 `wiki/courses/<slug>.md` — 写（1.0）
4. 写课程页内容 — 登记材料，教材进 `raw/books/` 须用户同意 — 写

### 1.2 新建课程 / 制定计划（:46、:115、:145、:158，原文未编号）
1. 判断是否周期课 — `cycle.mjs overview --json` — 不写
2. 定原书方式 — 主项「讲后读（错开）」，其他问一句 — 写 Key Facts
3. 定课程骨架 — 教材目录切课次 — 写
4. 列课次 — 临时 JSON（不写日期、不估时长）— 写临时文件
5. 预览排期 — `course-schedule.mjs plan … --lessons` — 不写
6. 写入排期 — 1.0 路径 + `plan --write` — 写
7. 排不下 — 周期内排满，剩下进「留到下个周期」 — 等用户定
8. 主项写周核实项 — This Week — 写
9. 登记索引 — `index.md ## Courses` — 写
10. 科目页补链接 — 写
11. 校验 — `cycle.mjs check` — 不写

### 1.3 开课（:132，1–8，任一步报错就停）
1. 确认会话 — 是「今天这门课」的会话，否则停 — 不写
2. 读课程页和偏好 — 课程页整页一次 + `profile.md` + 科目页 `## 讲解偏好` — 不写
3. 顺延 — `course_close shift`（有变化才提交，jj 记「顺延」）— 写
4. 查角色 — `cycle.mjs day --json` 的 `roles[slug]` — 不写
5. 问讲后读 + 回忆题 — 主项课；读了就 `note`，打勾留到收课 — `reading-queue.mjs note` — 写 Reading Log
6. 定核心页 — 主项课，原书一次 ≤ 10 页 — `pdftotext -f -l` — 不写
7. 今日要点框 — 第一条回复开头 — 不写
8. 按 teach 讲 — teach 2.1 — 不写

### 1.4 顺延（开课第 3 步展开；:176、references/close.md）
1. stage 课程页 → 2. 暂存副本上顺延（越过结束日的进「留到下个周期」）→ 3. 校验（不过删暂存）→ 4. 提交，jj「顺延 <slug> <日期>」（无变化删暂存不写）→ 5. 一句话告诉用户
- **11-10 验收发现**：模型不认可顺延结果时会自己开事务手改日期。已加规则（SKILL.md 开课一节）：顺延结果照单接受，课程会话不手改排期日期，有异议请用户回总控改计划。

### 1.5 存档点（:128，原文未编号）
1. `course_close stage` → 2. 只改暂存课程页 `Next Session` → 3. `check` → 4. `commit`（`label: 存档点`，jj 记「存档点」，撤销收课不撤它）→ 5. 请用户开新会话

### 1.6 收课（:186 起，0–10；事务细节 references/close.md；11-10 整理 4 起编号与执行顺序一致）
0. 有没有上过课 — 没讲过就说「没有可收的」— 不写
1. 重读课程页 — 不写
2. 打勾 — 满足原条件才打 — 写暂存
3. 抵消 — 写暂存
4. 标注未完成 — 写暂存
5. 追加记录 — `### YYYY-MM-DD-NN` + `完成：<id>`，再 `course-state.mjs list` 核对 — 写暂存
6. 更新 Next Session — 写暂存
7. 日期截图 — 报告写进暂存根下 `.snapshot.json` → `course_close snapshot`（沙盒外出图）— 写暂存
8. 概念页 + index + log + 归档 → `check` → `commit`（conflict 就 abort 重来；看板由 commit 自动重画）— `course_close add/check/commit` — 写库
9. 核对与报告 — `committed: true` 才说已保存，末尾「这次改了」— 不写
10. 提议闪卡 — 只 `reviews=anki` 的主项课，3–8 张，确认后写 — `flashcards.mjs add` — 确认后写

### 1.7 撤销收课（:199）
1. `course_close undo` — 改过的文件恢复，提交「撤销收课」— 写库
2. 安全闸 — 之后又被改过就拒绝 — 不写
3. 列出新建页 — 概念页、卡片页保留，问删不删；Anki 不动 — 不写

### 1.8 周核实（references/weekly-check.md，1–4）
1. 确认主项课、重读课程页 → 2. 出 2–3 道无提示题 → 3. 核对、打勾、写记录（经 course_close）→ 4. 一句话汇总给总控

### 1.9 改计划（散见 :113、:122–123、:158–180，未编号）
1. 重读课程页 → 2. 保留旧计划 → 3. 重排 `plan --write`（1.0）→ 4. `log.md` 记 `course` → 5. `cycle.mjs check`

### 1.10 讲解偏好（:127）
