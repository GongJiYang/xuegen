# 学根待做方向（2026-11-09 汇总）

编号对应 `xuegen/docs/platform/SKELETON.md`（功能骨架）的叶子。

## A. 先讨论：决定后面怎么做

1. **会话进程架构**（参照 Erlang）
   - 每个会话一个轻进程：总控、每门课、每本书、每个领域各一个。
   - 每类会话带一张固定的读写权限清单：工具层检查路径，执行命令时再加 macOS 系统沙盒。
   - 主管负责出错重启；会话之间不共享状态，只通过库交换结果，库里每个文件只有一个写入者。
2. **收课事务化**
   - 收课时先把改动写进暂存区，最后一次性提交并上锁。
   - 中途断线（比如今天的 terminated）时，就重做或回滚，不留下没上锁、写了一半的课程页。
3. **RAG：领域长期记忆（骨架 7.4）**
   - **检索范围**：这个领域的 wiki、原书、摘录、过去的课程会话。
   - **回答方式**：每句都标出处，比如「Epp p.47」「离散 D2 课 11-09」；库里没有就直接说没有，不编。
   - **第一步**：先用关键词检索。资料多了以后再加向量索引，那时要决定用本地模型还是 API 做嵌入。
   - **权限**：它只读、不写，正好对应第 1 条里「只读」的那类会话。
   - **为什么放在这一节先讨论**：要先定它的检索范围和权限，以及每个领域的总控会话是不是一个独立进程。
