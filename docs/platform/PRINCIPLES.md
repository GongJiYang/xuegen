# 学根准则（所有改动先对照）

2026-11-08 与用户讨论定下。任何代码、技能、库规则的改动都不得违反下面各条；确实需要违反时，先停下问用户，改了准则再动手。审查时逐条对照。

每条后面的状态：**生效** = 现在就照做；**待落地** = 已定、还没改完，新代码按目标写，不再扩大旧做法。

## 1. 库里只有四类东西

| 类 | 是什么 | 位置 | 谁写 |
|---|---|---|---|
| 原料 | 书、论文、文章、剪藏；外界给的，不变 | `raw/`、`Clippings/` | 用户放入；AI 只读 |
| 知识 | 从原料提炼的「什么是真的」，每条有出处 | `wiki/知识/`：`sources/ concepts/ entities/ synthesis/ extracts/ flashcards/` | AI 维护 |
| 意图 | 为什么学、学什么、按什么顺序、怎么讲 | `wiki/` 根下：`profile.md`、`subjects.md`、`subjects/`、`cycles/` | 用户定，AI 记 |
| 进度 | 做到哪、证据是什么 | `wiki/` 根下：`courses/`、`reading/`、`calendar/` | AI 记 |

另有：规则 `AGENTS.md`（库根）；流水与目录 `wiki/log.md`、`wiki/index.md`；生成物 `wiki/courses.md`、`wiki/*.html`（可重建，不手改）。

- 新增任何目录或文件类型，先归入四类之一，写进库 `AGENTS.md`；归不进去就不加。（生效）
- 知识目录收进 `wiki/知识/`，其余目录原地不动。（待落地：迁移与发版同一天做）

## 2. 原料只有一个入口，课程只引用原料

- 一切要学的材料先进 `raw/`（教材 PDF 复制到 `raw/books/`），再在 `知识/sources/` 登记。（待落地：教材还在 `~/Documents/学习路径/`）
- 课程不是原料：课程页只写「用哪几份 source、怎么排、做到哪」，不装材料内容，不写原文绝对路径（指向 source 页）。（生效；旧页里的绝对路径随迁移改）
- 上课就是摄入：一节课讲一节书，概念页写进 `知识/concepts/`，frontmatter 写 `sources:`（书的 source 页 + 节与页码）。书的 source 页是这本书的总账。不对整本教材做 Ingest。（新写的概念页生效；旧概念页不补）

## 3. 一件事只在一个地方

| 要知道的 | 只在这里 |
|---|---|
| 今天上哪节课、学完没有 | 课程页 `Today` + 排期表 |
| 讲后读读哪几页、哪天读 | 课程页 `Today` 那一行 |
| 这本书读到哪、下次读什么、读过哪些页 | 阅读页 `wiki/reading/<书>.md` |
| 哪天是什么日子、周期起止、课次总数 | 周期页 `cycles/cN.md` |
| 计划改过什么 | `wiki/log.md`（课程页 Learning Record 只放收课与周核实） |
| 怎么讲（偏好） | 见第 5 条的分层 |
| 学到的知识 | `wiki/知识/` |

- 写一件事之前先查它归哪里；别处只放链接，不抄内容。（生效）

## 4. 以文件为准，会话可以随时丢

- 状态只在 Markdown 文件里；会话记得的东西与文件不符时按文件。（生效）
- 不靠自动压缩或会话历史保存任何东西。压缩只是兜底。（生效）
- 每门课每天一个会话；跨天的东西只能经文件传递。（生效）

## 5. 记忆：分层 + 作用域隔离

| 层 | 位置 | 记什么 | 谁读 | 谁写 |
|---|---|---|---|---|
| 全局 | `wiki/profile.md` | 用户这个人：文案要简洁、不估时长、默认风格 | 所有会话 | 仅用户明确要求时；平时只读 |
| 科目 | 科目页 `## 讲解偏好` | 这一科怎么讲 | 该科目的课 | 该科目的课，经用户确认 |
| 课程 | 课程页 `Key Facts` | 本课特有约定（页码换算等） | 这门课 | 这门课 |
| 会话 | 只在对话里 | 「这次」的临时要求 | 本会话 | 不落盘 |

- 隔离：课程会话只读全局 + 本科目 + 本课程三层，不读、不写其他科目的偏好。总控可读各层，只写全局。（待落地）
- 一层一份档案：固定字段、原地更新，每层不超过 15 行，不追加流水。（待落地）
- 只在用户说「以后都…」或确认后写入；「这次…」只算会话层。不做后台自动抽取。（待落地）
- 冲突：范围窄的优先（会话 > 课程 > 科目 > 全局）；同层新的替换旧的，写上日期。（待落地）
- 偏好进记忆，进度进课程页，知识进 `知识/`，三者不混。（生效）
- 界面上选的讲解风格只管本次会话；长期默认写在科目层。（待落地：现在 `desktop.json` 的 `courseStyles` 与课程页「讲解风格」两处冲突）

## 6. 上下文有预算

- 每次必读的文件有上限：课程页约 200 行，Learning Record 只留最近 2 次收课，更早的移到 `courses/<slug>/records/YYYY-MM.md`；`log.md` 只读末尾；技能读过一次不全文重读。（待落地）
- 一个会话里课程页整页只读一次；之后只读要改的那一节，改完不整页重读，除非文件在会话外被改过。（待落地）
- 原书按页读，一次不超过 10 页；不整章导出，导出结果不整段打印进对话。（待落地）
- 一节课约 25 万 token 预算：到 60% 先写存档点（当前题目、作答到哪、下一步）进课程页，再提示「存档后开新会话」；自动压缩前也先存档。（待落地，需应用端）
- 目标：D1 与 D15 开课时读入的量相同，与学过多少节无关。

## 7. 读原书（主项课）

- 讲后读（错开）：核心页开课时定，收课时在 `Today` 写一行，读在另一门主项的下一个上课日，下次开课时问。读完记进该书阅读页的 Reading Log。（生效；Reading Log 待落地）
- 原书通读：交给阅读队列，一本书一个阅读页；两门主项每 14 天一段、错开一周轮流；从 `position` 往后读，已读的核心页跳过。分段只排顺序，不写日期。（待落地：需阅读脚本支持 `wiki/知识/sources/` 作原文与固定间隔）
- 不估任何时长或读完日期；落后不算逾期。（生效）

## 8. 向量检索（以后再做）

- 向量索引是生成物：可从文件重建，放在库外（`~/.xuegen/index/`），删了不丢东西。
- 只索引 `知识/` 与 `raw/`（教材按页切块，结果带书名页码）；意图、进度、记忆不进索引，它们按路径精确读取。
- 检索只负责找到；回答前打开原文件，以文件为准。关键词 + 向量混合。
- 不新增数据库保存状态（见仓库 `AGENTS.md`）。

## 9. 取舍记录

参考过 llm_wiki（nashsu）、LangMem、Mem0、Letta：

- 取：三层分离与 Ingest/Query/Lint（Karpathy）；每页 `sources:` 出处；记忆分层命名空间与 profile 原地更新（LangMem）；共享块只读、块有长度上限（Letta）；按作用域过滤读写（Mem0）。
- 不取：知识图谱、社区检测、深度研究、审核队列等新功能；整本教材自动摄入；后台自动抽取记忆；向量库作记忆；另换 Agent 框架。
