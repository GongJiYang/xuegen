# 查 bug 的流程（用户 2026-11-11 定，取代「全量测试一次」的做法）

起因：11-10/11 全量测试后，11-11 真机仍发现 6 处问题（已收课仍显示开课、今日卡 Anki 无张数、讲后读行有「核心页」且括号套括号、「读书」旧叫法、每天提示「还没有书」、带读名字重复）。漏网原因四类：
1. **同一事实多处显示、各算各的**（今日卡 vs 总进度的「完成」，今日卡 vs 右侧面板的 Anki 张数）；没有跨处一致性测试；全量测试收课后没回看今日卡。
2. **用词规则只在文档**：词表在 SKIN-LEDGER，没有机器检查；用户可见文字散在 strings.ts、脚本输出（如 calendar.mjs）、技能示例三处。
3. **测试按功能列，不按「一天里的状态」列**：收课后、讲后读过期、书晚了这类状态没有被覆盖。
4. **界面验收靠肉眼、日期不可控**：截图无断言；13 个文件直接 `new Date()`，测试窗口无法停在指定日期。

## 五项改进（按顺序做）
1. **用词闸门**：`scripts/lint-wording.mjs`，禁用词从 `docs/desktop/SKIN-LEDGER.md` 第三节「不要用」列读取（机器可读的那一列），扫 `apps/desktop/src/renderer/**/*.ts(x)` 的字符串字面量、`skills/**/*.mjs` 写到 stdout 的文字、`skills/*/SKILL.md` 的示例块；注释与「内部词」白名单另列。接进根 `npm test`。
2. **一件事只算一次**：课次完成状态、今日 Anki 张数、讲后读行文字各做成一个共用纯函数，今日卡 / 右侧面板 / 总进度 / 日历都调它；加「跨处一致性」测试：同一份数据进几个视图，显示的事实相同。
3. **日期可指定**：桌面主进程、渲染进程、脚本统一认 `XUEGEN_TODAY=YYYY-MM-DD`（不设时用本机日期）。
4. **场景表 + 自动走查**：约 12 种日内状态（开课前、收课后、撤销后、讲后读到期 / 过期、书房晚了、Anki 开 / 关、整合日、休息日、周期最后一周、带读跨周期），每种一份固定库 + `XUEGEN_TODAY`；脚本开测试窗口（CDP 9460），**读出每个面板的文字逐条断言**，并截图留档。每批改到界面的活、每次发版前都跑。
5. **任务单与发现表两栏**（立即执行）：
   - 任务单必须有「这个事实 / 这段文字还在哪些地方显示」一节（附 grep 结果），审核逐处核对。
   - 发现表每条加「为什么之前没抓到」和「防这一类的测试」两列。
