# 高阶函数

## Definition

**高阶函数**（higher-order function）是接受函数作为参数或返回函数的函数。

## How It Works

- 把循环里的「做什么」抽成参数，循环结构本身可以复用。
- 组合高阶函数能写出声明式的数据处理。
