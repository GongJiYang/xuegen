# 状态

## Definition

**状态**（state）是程序在两次操作之间保留下来、会影响后续结果的数据。

## How It Works

- 赋值让同一个表达式在不同时刻得到不同结果。
- 状态让程序更难推理，因为结果依赖执行顺序。
